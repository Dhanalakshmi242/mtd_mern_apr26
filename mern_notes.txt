	   Cluster Name : Clustor0 (default)
	   Provider : AWS Cloud
	   Create Deployment
	4. Side Menu Bar -> Clusters
	   If "Connect" is there
	   we may connect from our computer
	   Need :
		1.Username
		2.Network inbound connection
	5. Under security (left side menu bar)
	  -> Database and Network Access
	  Username : Dhanalakshmi
	  Password : 1234
	  Role : Built-in-role : Atlas Admin
	  -> Add User
	6. Under Security (left menu bar)
	  -> Database and Network Access
	  -> IP Access List
	  -> Add IP Address
	  -> Access List Entry - 0.0.0.0/0 (Everyone can access my database)
	  -> Confirm
	7. Ready to connect to cloud Mongo server
	7.1 Connect via Mongo Shell
	    Side Menu Bar
	   -> Clusters
	   -> Connect
     	   -> Shell

		-> Download the shell
		-> Install

		mongosh "mongodb+srv://cluster0.icofcfw.mongodb.net/" --apiVersion 1 --username Dhanalakshmi
